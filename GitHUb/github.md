# GitHub Documentation

## 1. Introduction

GitHub is an online platform used to host Git repositories and collaborate on projects.

## 2. Important Features

- Repository hosting
- Version control
- Collaboration
- Pull requests
- Issue tracking
- Project management

## 3. Creating a Repository

1. Login to GitHub.
2. Click the New Repository option.
3. Enter repository name.
4. Select Public or Private.
5. Click Create Repository.

## 4. Connecting Local Repository

```bash
git remote add origin REPOSITORY_URL
```

## 5. Uploading Project

```bash
git add .
git commit -m "Initial commit"
git push -u origin main
```

## 6. Cloning a Repository

```bash
git clone REPOSITORY_URL
```

## 7. Pulling Changes

```bash
git pull origin main
```

## 8. Fork and Pull Request

- Fork: Creates your own copy of another repository.
- Pull Request: Requests merging your changes into another repository.

## 9. Advantages of GitHub

- Online project storage.
- Team collaboration.
- Project history.
- Open-source development.
- Easy code sharing.

## 10. Conclusion

GitHub is a useful platform for managing projects and collaborating with other developers.
