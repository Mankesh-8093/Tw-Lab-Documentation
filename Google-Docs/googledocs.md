# Google Docs Documentation

## 1. Introduction

Google Docs is an online word-processing application developed by Google.

It is used to create, edit, format and share documents online.

## 2. Features of Google Docs

- Create and edit documents.
- Share documents with others.
- Real-time collaboration.
- Automatic saving.
- Add images, tables and links.
- Download documents in different formats.

## 3. Creating a Document

Steps:

1. Open Google Docs.
2. Sign in using a Google account.
3. Click on Blank Document.
4. Enter the document title.
5. Start writing content.
6. The document is automatically saved.

## 4. Text Formatting

Google Docs provides different formatting options.

- Bold text
- Italic text
- Underline text
- Font size and font style
- Text alignment
- Text color

## 5. Inserting Elements

Google Docs allows users to insert:

- Images
- Tables
- Charts
- Links
- Page numbers
- Headers and footers

## 6. Sharing Documents

Steps:

1. Open the document.
2. Click the Share button.
3. Enter the email address.
4. Select the permission.
5. Click Send.

### Sharing Permissions

| Permission | Purpose |
|---|---|
| Viewer | Can only view |
| Commenter | Can add comments |
| Editor | Can edit the document |

## 7. Version History

Google Docs maintains previous versions of documents.

Steps:

1. Open the document.
2. Click File.
3. Select Version history.
4. Click See version history.
5. View or restore an earlier version.

## 8. Downloading Documents

Google Docs supports different file formats:

- PDF
- Microsoft Word (.docx)
- Plain Text (.txt)
- EPUB

Steps:

1. Click File.
2. Select Download.
3. Choose the required format.

## 9. Advantages of Google Docs

- Free online document editor.
- Automatic saving.
- Easy collaboration.
- Accessible from different devices.
- Easy document sharing.

## 10. Conclusion

Google Docs is a useful online application for creating, editing and sharing professional documents.
